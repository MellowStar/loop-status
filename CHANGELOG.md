# Changelog

## 0.1.0

First release.

- `run` / `start` / `stop` / `serve` / `doctor` / `set` / `init`.
- A per-issue status page with stat tiles, state filters, a timeline, a log viewer (claude-json summaries and text
  tails) and a reviews tab. Light and dark themes come from the config.
- `template/`: a sample loop with a demo mode, `status-hooks.sh`, sample outputs and an agent guide.
